# AI-Powered Financial Fraud Detection and Risk Analysis System

## Project Overview

This project is a machine learning-based financial fraud detection system that analyzes transaction patterns and identifies potentially fraudulent transactions.

The project uses machine learning models to predict whether a transaction is fraudulent or legitimate and provides fraud probability and risk analysis. A Power BI dashboard is also developed to visualize fraud patterns and key transaction insights.

## Objectives

- Detect potentially fraudulent financial transactions
- Analyze transaction patterns and suspicious factors
- Compare machine learning classification models
- Predict fraud probability for new transactions
- Perform risk analysis and provide recommendations
- Visualize fraud insights using Power BI

## Technologies Used

## Machine Learning Models

### Logistic Regression
Used as a classification model to predict whether a transaction is fraudulent or legitimate.

### Random Forest
Used as the main classification model to capture relationships between different transaction features and identify important fraud-related factors.
